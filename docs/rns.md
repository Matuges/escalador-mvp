# Regras de negócio
RN01 — Uma pessoa só pode ser escalada em uma função para a qual esteja qualificada.
RN02 — A indisponibilidade declarada por uma pessoa deve sempre ser respeitada.
RN03 — Nenhuma pessoa deve ultrapassar seu teto de escalas no ciclo.
RN04 — Pares marcados como "evitar" não devem ser alocados no mesmo culto.
RN05 — Uma alocação fixada manualmente não pode ser alterada pela geração automática.
RN06 — A demanda de cada função em um culto deve ser integralmente preenchida para a escala ser considerada completa.
